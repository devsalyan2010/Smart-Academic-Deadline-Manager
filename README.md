# Smart Academic Deadline & Workload Manager

## Project Overview

The Smart Academic Deadline & Workload Manager is a Python-based system designed to help students organize and manage their academic assignments.

The system allows users to store assignment details, track deadlines and completion status, search assignments, analyse priority, and understand their overall academic workload.

## Problem Statement

Students often have multiple assignments, tutorials, and projects with different deadlines. Managing these tasks manually can make it difficult to keep track of deadlines and decide which assignments require greater attention.

This project provides a simple Python-based solution for storing assignment information and performing priority and workload analysis.

## Main Features

- Add and store academic assignments
- View stored assignments
- Search assignments
- Track assignment status
- Perform priority analysis
- Perform workload analysis
- Display a student dashboard
- Store data using CSV file handling
- Validate user inputs

## Computational Feature

The system calculates assignment priority using factors such as:

- Deadline urgency
- Assignment difficulty
- Estimated completion time

Assignments are classified into:

- High Priority
- Medium Priority
- Low Priority

The system also calculates workload information such as total estimated hours, assignment status, priority distribution, and deadline-related information.

## Python Concepts Used

The project demonstrates:

- Variables and data types
- Conditional statements
- Loops
- Lists and dictionaries
- Functions
- File handling
- Exception handling
- CSV processing
- Date and time processing
